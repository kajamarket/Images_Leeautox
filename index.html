GitHub Pages Hosting & Deploy Guide
Hosting on images.leeautox.com:
  1. Single File: Place this index.html at the root of your GitHub repository.
  2. Image Folder: Upload your vehicle photos to the public/cars/ folder in the repository.
  3. GitHub Pages Setup: In your GitHub repository Settings → Pages, choose Deploy from a branch (branch: main, folder: / (root)).
  4. Custom Domain: Under Custom domain, type images.leeautox.com, check Enforce HTTPS, and point your DNS CNAME record for images to <username>.github.io.
