Pre-configured for images.leeautox.com & kajamarket/Images_Leeautox

This codebase is already configured with a root CNAME, .nojekyll, and GitHub Actions workflow so it deploys automatically to GitHub Pages:

  1. Images Folder: Whenever you push or drag-and-drop car photos into public/cars/ on GitHub, this site automatically displays them immediately.
  2. GitHub Pages Setting: In GitHub repo kajamarket/Images_Leeautox → Settings → Pages:
    • Source: Deploy from a branch → main / / (root)
    • Custom domain: images.leeautox.com (Enforce HTTPS checked)
  3. DNS Record: In your domain DNS manager, set CNAME:
    images → kajamarket.github.io
